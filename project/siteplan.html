Project Owner: Timothy Ebil

1. Site Name & Naming Conventions

Explore Uganda: The Ultimate Regional Adventure & Ecofriendly Tourism Hub

Selection Rationale: This brand identifier directly establishes the web ecosystem as a robust regional directory. It balances adrenaline-based tourism highlights with an explicit commitment to eco-friendly exploration. All files follow the course convention path: placed entirely inside a lowercase subfolder named project with lowercase extensions.

Target Project Files Mapping:

  • Relative Folder Structure: wdd131/project/
  • Planning Layout Target: project/siteplan.html
  • Production Index View: project/index.html
  • Application Engine Script: project/app.js
  • Style Grid Sheet Layout: project/styles.css

2. Site Purpose

The core purpose of this site is to serve as an interactive, fast-loading engineering showcase highlighting Uganda's premier destination clusters. Unlike basic informational brochures, this portal targets low-bandwidth travel configurations by implementing responsive srcset picture views. Furthermore, it integrates functional client-side algorithms to evaluate weather comfort dynamics alongside high-performance array filters to sort terrains instantly without forcing page reloads.

3. Target Audience Scenarios

The platform architecture addresses explicit user challenges defined by the target audience scenarios below:

  • Scenario A: "I am planning a trip to climb the Rwenzori slopes, but I need to quickly calculate if the combination of high winds and low temperature creates a dangerous wind chill before I go."
  • Scenario B: "I am currently traveling using a slow, remote mobile network data plan in rural Uganda. How can I instantly filter for just forest or savanna locations without triggering expensive whole-page content reloads?"

4. Color Schema

The visual identity uses natural, high-contrast, environmentally relevant tones to match the eco-tourism concept:

Primary Green (#1B4332)
Semantic Headings & Section Borders
Accent Gold (#FFB703)
Interactive Filters & Calculated State Badges
Charcoal Black (#212529)
High-Contrast Body Paragraphs
Off-White Canvas (#F8F9FA)
Document Wrapper Backgrounds

5. Typography

  • Heading Elements (h1, h2, h3, h4): "Trebuchet MS", "Lucida Grande", sans-serif
    Application Plan: Used to build heavy, geometric structural anchor lines over content blocks.
  • Body Content Elements (p, li, labels, small): "Segoe UI", Roboto, Helvetica, Arial, sans-serif
    Application Plan: A highly legible system typeface that matches dynamic text density across varied viewports.
